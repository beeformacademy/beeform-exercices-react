Exercices React — Beeform Academy

Copie pédagogique du dépôt OpenClassrooms-Student-Center/8710331-debutez-avec-react. Le code, ses auteurs et son historique sont conservés. Ce guide est le seul fichier ajouté sur main.

Choisir son exercice

Suivez le lien de la leçon pour choisir la branche Begin ou Solution. La branche main n’est pas le corrigé de tous les exercices. Les noms de branches sont conservés ; les liens commits affichent l’historique de l’étape.

Travailler localement

git clone https://github.com/beeformacademy/beeform-exercices-react.git
cd beeform-exercices-react
git switch P2C1-Begin
npm install
npm run dev

Ouvrez l’adresse locale affichée par Vite. Utilisez une version de Node compatible avec la version de Vite du projet (le contrôle Beeform utilise Node 22.13). Vous pouvez aussi choisir Code puis Download ZIP sur la branche souhaitée. Décompressez entièrement les fichiers et placez-vous dans le dossier contenant package.json.

Travaillez localement ou dans un fork personnel ; aucun droit d’écriture sur le dépôt modèle n’est nécessaire. Sauvegardez vos essais avant de changer de branche. Les erreurs et étapes incomplètes des branches Begin font partie des exercices.

Pour construire la version locale : npm run build. Les adaptations éditoriales des supports, dont le message de salutation Beeform, ne réécrivent pas l’historique source.
